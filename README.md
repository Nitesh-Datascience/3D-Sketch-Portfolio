# Nitesh Kumar — 3D Sketch Portfolio

A playful, hand-drawn-looking 3D portfolio built with HTML, CSS, JavaScript and Three.js.

## Run locally
Open `index.html` in a modern browser while connected to the internet (Three.js, Tween.js and Google Fonts load from CDNs). For a local server, use VS Code Live Server.

## Deploy on GitHub Pages
1. Go to **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then Save.
4. Open the Pages URL shown in the settings.

## Interactions
- Click/tap the entrance door to open it and enter the hallway.
- Click/tap a room door to see its information and links.
- Drag to look around; pinch to zoom on supported touch screens.
- Use the sound button to play a short tone.

## Personalize project links
Edit the project links in the `door(... 'The Gallery' ...)` section in `index.html`. The Telecom Churn, Nifty Prediction, and Smart Water Tank Monitoring links are placeholders until you add their real URLs.

## Notes
This is a static front-end project; no backend or build step is required. The 3D libraries are loaded from public CDNs, so an internet connection is needed.
